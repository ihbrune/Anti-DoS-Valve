Anti-DoS Valve config helper

Create and customize your valve configuration for Apache Tomcat (server.xml or context.xml). Further explanations are available in the README. To test the impact of your settings against different traffic patterns, check out the Traffic & Attack Simulator at the bottom of the page.

🍪 Visitor Tracking & Reputation Cookies
Optional Feature
Issues encrypted, tamper-proof AES-256-GCM visitor tokens (_adv) bound to client IP subnets. Distinguishes first-contact requests from returning visitors without session cookies or server-side session state.
Optional
Cookie name used to track returning visitors. Default: _adv.
Optional
256-bit AES secret key (64 hex chars, 44 Base64 chars, or passphrase ≥ 16 chars). Leave empty to auto-generate a secure ephemeral key in memory on startup (recommended for single nodes; configure identical secret across multi-node clusters).
Optional
Validity lifetime of the visitor cookie in seconds (≥ 1). Default: 900 (15 minutes).
Optional
Threshold ratio of remaining TTL before refreshing the cookie (0.01 – 0.99, max. 2 decimal places). Default: 0.5 (refreshes when remaining lifetime falls below 50% of TTL).
Optional
IPv4 prefix length for cryptographic subnet binding (0 – 32). Default: 24 (/24 subnet binding).
Optional
IPv6 prefix length for cryptographic subnet binding (0 – 128). Default: 64 (/64 subnet binding).
Optional
Cookie path attribute. Default: /.
Optional
SameSite attribute for the cookie (Lax, Strict, None). Default: Lax.
