Anti-DoS Valve config helper

Create and customize your valve configuration for Apache Tomcat (server.xml or context.xml). Further explanations are available in the README. To test the impact of your settings against different traffic patterns, check out the Traffic & Attack Simulator at the bottom of the page.

Evaluated before relevantPaths. Explicitly excludes matching URLs from rate limiting (e.g. static CSS/JS/images or public status endpoints).
Optional
When enabled (serverWideBlocking="true"), an IP address (or aggregated subnet) blocked on relevantPaths is blocked across all server paths. Requests to unmonitored paths are not counted, but blocked clients are rejected. Whitelisted paths in nonRelevantPaths remain accessible.

Subnet prefix length for aggregating IPv4 addresses (1 to 32, e.g. 24, /24, or 255.255.255.0). 32 or empty disables aggregation.
Optional
Subnet prefix length for aggregating IPv6 addresses (1 to 128, e.g. 64 or /64). 128 or empty disables aggregation.
Required
Length of a time slot in seconds (≥ 1). Requests are counted within consecutive non-overlapping slots.
Required
Maximum permitted requests within a slot before an IP address or subnet is blocked (≥ 1).
Required
Number of historical slots the monitor retains (≥ 1). At 1, the monitor has no memory beyond the current slot.
Required
Multiplier for transferring the average request count from previous slots into the new slot (≥ 0.0). 0 disables retention; > 1 penalizes longer.
Optional
Operation mode: BLOCKING (returns HTTP error code) or MARKING (sets request attribute org.henbru.antidos.AntiDoS).
Optional
Simulation mode: logs actions without actually blocking or marking any requests. Useful for testing configurations in production.
Optional
HTTP status code returned when a request is blocked in blocking mode (100–599). Default: 429 (Too Many Requests). Legacy: 403.
