How Block Diagnosis Investigates User Complaints

Enter a client IP address, a User-Agent string (or fragment), a requested URL/path, or any combination above. If an exact incident timestamp is specified, the lookup centers the search window around that time using the chosen +/- tolerance; otherwise it checks the Lookback Window from now.

1. IP & Network Intel
Resolves canonical /24 or /64 subnet, private RFC ranges, ASN/Org, verified crawlers, threat intel feeds, and saved Network Notes.
2. Static Lists & Mitigation Bypass
Simulates alwaysForbiddenIPs, alwaysAllowPrivateIPs, alwaysAllowedIPs, mitigationBypassPrivateIPs, and mitigationBypassIPs.
3. Dynamic CIDR & UA Rules
Checks overlapping active/historical CIDR rules, User-Agent hash signatures, context bypasses (Auth / Returning / Private IP), and audit history.
4. Telemetry & Pipeline Match
Searches client_events (including /24 or /64 collateral rate-limits), hourly subnet rollups, and Valve URL/Auth scope regex rules.
